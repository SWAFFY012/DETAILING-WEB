# SITE-CONSTRUCTOR

Одностраничный сайт детейлинг-студии. Статика: HTML, CSS и JS без сборки — репозиторий можно
клонировать на любую машину и сразу продолжать работу, все фотографии и видео лежат внутри.

## Запуск

Отдельная сборка не нужна. Достаточно поднять любой статический сервер из корня репозитория:

```bash
python -m http.server 8080
```

Затем открыть http://localhost:8080

Открывать `index.html` напрямую двойным кликом (протокол `file://`) не стоит: часть браузеров
в этом режиме блокирует автозапуск фонового видео в Hero-секции.

## Структура

| Путь | Содержимое |
| --- | --- |
| `index.html` | Вся страница: шапка, Hero, услуги, калькулятор, преимущества, до/после, карусель работ, отзывы, форма записи, контакты, футер |
| `privacy.html` | Политика конфиденциальности |
| `css/styles__536589.css` | Базовая вёрстка и типографика |
| `css/theme.css` | Слой оформления: цветовые токены, Hero, карусель работ. Подключается **после** базового файла и перекрывает его переменные |
| `css/fonts__5a8024.css` | Подключение локальных шрифтов |
| `js/main__5f8b97.js` | Общие скрипты страницы |
| `assets/` | Логотип, фотографии услуг, до/после, `works-carousel/` — снимки работ для карусели |
| `video/hero.mp4` | Фоновое видео Hero-секции |
| `fonts/` | Шрифты в формате woff2 |

## Как менять оформление

Цвета, скругления, шрифт и ширина контейнера собраны в `:root` файла `css/theme.css`.
Основной акцент задаётся переменными `--clr_main` и `--clr_secondary`; переменные `--gold`
и `--gold-2` сохранены ради совместимости с базовым стилем и указывают на тот же акцентный цвет.
Правка одного значения меняет кнопки, заголовки, иконки и активные состояния по всему сайту.

Чтобы вернуться к исходному оформлению, достаточно убрать из `index.html` одну строку
с подключением `css/theme.css` — базовый файл при слиянии не изменялся.

## Hero-секция

Фоновое видео зациклено тремя независимыми механизмами, чтобы воспроизведение не прерывалось:
атрибут `loop`, обработчик события `ended` с перемоткой в начало и повторный запуск при
возврате на вкладку (`visibilitychange`). Атрибут `muted` обязателен — без него браузер
блокирует автозапуск.

Переключатель услуг под заголовком листается автоматически раз в 6 секунд, а также стрелками
и кликом по кнопке услуги. Тексты заголовка и подзаголовка для каждой услуги хранятся прямо
в разметке, в атрибутах `data-title` и `data-sub`.

## Карусель работ

Секция `#gallery`: две строки с горизонтальной прокруткой и привязкой к плиткам
(`scroll-snap`). Нижняя строка сдвинута вправо через `margin-left` у первой плитки — задавать
сдвиг через `padding-left` контейнера нельзя, прокрутка его поглощает. Стрелки прокручивают
обе строки синхронно на ширину одной плитки. Подписи к работам появляются при наведении,
на мобильных показаны постоянно.

Чтобы добавить работу: положить изображение в `assets/works-carousel/` и скопировать в нужную
строку блок `<figure class="works__item">` с новым путём и подписью.

## Что осталось сделать

Форма записи и форма обратного звонка сейчас работают только на стороне браузера — отправки
заявок не происходит. Нужен обработчик на сервере или сторонний сервис приёма форм.
